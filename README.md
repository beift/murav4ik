# Муравей

## Описание проекта

«Муравей» — это приложение, разработанное на языке программирования C# с использованием технологии WPF.

Программа представляет собой игровое поле, состоящее из клеток двух цветов: чёрного и белого. На поле находится муравей, который может перемещаться по клеткам и выполнять заданные пользователем команды.

## Возможности программы

- Создание игрового поля с заданным количеством строк и столбцов.
- Случайное расположение чёрных и белых клеток.
- Случайное начальное положение муравья.
- Выбор направления движения муравья.
- Добавление и удаление команд для чёрных и белых клеток.
- Поворот муравья направо и налево.
- Перемещение муравья вперёд.
- Изменение цвета клетки.
- Запуск и остановка выполнения команд.
- Сброс поля к начальному состоянию.
- Анимация движения и поворота.

## Используемые технологии

- **C#** — язык программирования.
- **WPF** — технология создания графического интерфейса.
- **XAML** — описание внешнего вида приложения.
- **.NET** — платформа для запуска приложения.

## Структура проекта

```text
muravei/
│
├── App.xaml
├── App.xaml.cs
├── MainWindow.xaml
├── MainWindow.xaml.cs
```

### Основные файлы

- `MainWindow.xaml` — внешний вид главного окна и игрового поля.
- `MainWindow.xaml.cs` — основная логика программы, движение муравья и выполнение команд.
- `Cell.cs` — класс, описывающий клетку игрового поля и её цвет.
- `App.xaml` — настройки запуска приложения.
- `App.xaml.cs` — класс приложения.

## Как запустить проект

1. Скачайте или клонируйте репозиторий.
2. Откройте файл решения проекта в Visual Studio.
3. Дождитесь загрузки и восстановления необходимых компонентов.
4. Запустите приложение клавишей `F5`.

## Управление

1. Укажите количество строк и столбцов.
2. Создайте игровое поле.
3. Добавьте команды для белых и чёрных клеток.
4. Нажмите кнопку запуска.
5. При необходимости используйте паузу или сброс.

## Назначение проекта

Проект создан в учебных целях для практики программирования на C#, работы с WPF, коллекциями, событиями, анимацией и асинхронным выполнением команд.
